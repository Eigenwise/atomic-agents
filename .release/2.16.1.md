## Read before upgrading

- This release fixes a privacy leak in tracing. In 2.15.0 and 2.16.0, with `hide_inputs` on and `hide_outputs` off, a failed tool call, agent run or model attempt wrote the raw exception message and stack trace to the span's exception event and status description. A Pydantic validation error quotes the rejected input, so hidden tool arguments ended up in the trace. If you run with `hide_inputs=True` (or `ATOMIC_AGENTS_TRACE_HIDE_INPUTS=true`) and leave outputs visible, upgrade, and treat exception events in traces recorded by those two versions as possibly containing input values.

## Fixes

### Tracing

- Failure messages and exception stack traces are redacted when either `hide_inputs` or `hide_outputs` is set. The exception type and the error or attempt count are kept, for example `ValidationError: 1 errors (__REDACTED__)`. With both flags off nothing changes. (#403)
