## Features

- Activate Atomic Agents through the standard `opentelemetry-instrument` launcher. The bundled instrumentor now registers both OpenTelemetry and Phoenix discovery entry points.
- Share installation state across manual setup and both discovery paths, preventing duplicate agent and tool spans. The first installation keeps its provider and configuration.
- Skip missing optional tracing dependencies during automatic loading while preserving the install hint for manual setup.

## Verification

- Exercise installed entry points, the real loader and launcher, disabled instrumentation, privacy controls, teardown and reinstallation.
- Test current and minimum-supported telemetry dependencies.

Tracing remains optional. Runtime dependency requirements are unchanged. LLM spans still require a provider instrumentor, and `opentelemetry-bootstrap` does not install Atomic Agents automatically.
